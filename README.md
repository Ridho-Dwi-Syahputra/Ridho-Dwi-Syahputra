## `$ ls -la ./projects/`

<details>
<summary><strong>🛰️ ForestWatch Papua — Deep Learning Deforestation Detection System</strong></summary>

<br/>

> A production-grade geospatial AI system for detecting and monitoring deforestation in Papua, Indonesia, developed for the **SATRIA DATA 2026 SEC competition** (Subtema 1). The system leverages multi-source satellite imagery fused with a ResNet50-U-Net deep learning architecture to perform pixel-level semantic segmentation of forest loss across six land-cover classes.

| Attribute | Details |
|:----------|:--------|
| **Stack** | Python · TensorFlow · Google Earth Engine · Sentinel-2 · ResNet50-U-Net |
| **Data Sources** | Sentinel-2 (L2A) · ESA WorldCover · Dynamic World · Hansen GFC v1.13/2025 · BIOPAMA Oil Palm |
| **Architecture** | ResNet50 encoder + U-Net decoder · 6-class label schema · Consensus labeling |
| **Scale** | Papua province-level spatial coverage · Multi-temporal analysis |
| **Preprocessing** | Cloud masking · Band composition · Spectral index computation (NDVI, EVI, LSWI) |
| **Training** | Google Colab (T4 GPU) · Transfer learning from ImageNet weights |
| **Role** | ML Lead — GEE pipeline, preprocessing, model architecture, training |
| **Deliverables** | PRD · Project Guidebook · Essay Draft · Model Training Codebase |

**Six-class label schema:** Primary Forest · Secondary Forest · Oil Palm Plantation · Agriculture/Shrubland · Water Body · Non-Vegetated/Urban. Dataset consensus methodology applied across five independent geospatial sources to produce high-confidence ground truth labels for model supervision.
